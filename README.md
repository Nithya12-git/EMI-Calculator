# 💰 EMI Calculator

A modern and responsive EMI (Equated Monthly Installment) Calculator built using HTML, CSS, and JavaScript. This application helps users calculate their monthly EMI, total interest payable, and total payment amount based on the loan amount, annual interest rate, and loan tenure. It features a clean, interactive, and user-friendly interface.

## 🚀 Features

- Calculate Monthly EMI
- Calculate Total Interest Payable
- Calculate Total Payment Amount
- Instant calculation
- Responsive design
- Modern and intuitive user interface
- Input validation
- Easy-to-use layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ Installation & Usage

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/EMI-Calculator.git
   ```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.

4. Enter:
   - Loan Amount
   - Annual Interest Rate
   - Loan Tenure

5. Click **Calculate** to view:
   - Monthly EMI
   - Total Interest
   - Total Payment

## 📊 Output

The calculator displays:

- 💵 Monthly EMI
- 📈 Total Interest Payable
- 💳 Total Payment Amount
